# 🧠 Personality Assessment System

A full-stack personality profiling system that combines a fine-tuned **RoBERTa** classifier, a **Bayesian profile store**, an adaptive question bank, and a local **LLM** (Ollama) to assess MBTI type and HEXACO six-factor personality through natural conversation — running entirely on your machine.

---

## Features

- **MBTI classification** — 16-type prediction via fine-tuned RoBERTa (45.2% accuracy, 68.8% top-3)
- **HEXACO six-factor profiling** — binary classification per dimension (58.6% average accuracy)
- **Bayesian profile updates** — decayed prior × likelihood so early answers carry more weight
- **80-question bank** — 8 questions per dimension (5 open + 3 follow-up), tagged and indexed
- **Adaptive questions** — every 3rd question generated by a local LLM grounded in your previous answer
- **Entropy-based convergence** — session stops automatically when the profile is confident enough
- **Streamlit web app** — browser-based UI with live charts, radar plots, and a narrative report
- **Fully local** — no API keys, no data sent anywhere; classifier runs on Apple Silicon MPS

## Quick Start

### 1. Clone and set up environment

```bash
git clone <repo>
cd training

python3 -m venv .venv
source .venv/bin/activate

pip install torch transformers datasets scikit-learn \
            pandas numpy tqdm streamlit plotly ollama
```

### 2. Download datasets

```bash
pip install kagglehub
python data_download.py
```

### 3. Run the data pipeline

```bash
python phase1_eda.py        # Step 1 — exploratory analysis
python phase1_clean.py      # Step 2 — clean + split
python phase1_verify.py     # Step 3 — verify (79 checks)
```

### 4. Train the classifier

```bash
python phase2_model.py --epochs 10 --batch_size 16 --max_length 256
```

Training takes ~70 minutes on Apple Silicon M-series. Checkpoint saved to `outputs/phase2/best_model/`.

### 5. Set up Ollama (local LLM)

```bash
brew install ollama
ollama pull llama3.2    # ~2GB download
# Ollama auto-starts on macOS; no need to run ollama serve manually
```

### 6. Launch the web app

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

### Or run the CLI

```bash
python phase6_llm.py --max_turns 12
```

## Model

**Architecture:** `roberta-base` shared encoder with two task heads

| Head | Task | Loss | Output |
|---|---|---|---|
| MBTI | 16-class classification | CrossEntropy (class-weighted) | logits [16] |
| HEXACO | 6-dim binary classification | BCE (dim-weighted) | scores [6] |

**Multi-task loss:** `0.5 × L_MBTI + 0.5 × L_HEXACO`

**Training config:**
```
epochs=10, batch_size=16, max_length=256
lr=1e-5 (encoder), 1e-4 (heads)
warmup_ratio=0.1, weight_decay=0.01
early_stopping_patience=3
```

**Test set results:**

| Metric | Score | Baseline |
|---|---|---|
| MBTI accuracy | 45.2% | 6.25% random |
| MBTI top-3 accuracy | 68.8% | — |
| MBTI F1 macro | 0.360 | — |
| HEXACO avg accuracy | 58.6% | 50% random |

## Profile Store

`ProfileManager` maintains a live personality estimate using:

- **MBTI:** Log-space Bayesian update with decay — `posterior ∝ prior + decay^n × log_likelihood`
- **HEXACO:** Welford online mean + variance per dimension
- **Convergence:** Stops when MBTI entropy < 1.5 nats AND all HEXACO variances < 0.04

```python
from phase3_profile import ProfileManager

profile = ProfileManager()
profile.update(mbti_logits, hexaco_scores)   # after each answer
target  = profile.most_uncertain()           # what to ask next
done    = profile.is_converged()             # when to stop
report  = profile.to_dict()                  # full JSON snapshot
```

## Question Bank

80 questions across 10 dimensions:

| Dimension | Type | Questions |
|---|---|---|
| I/E, N/S, T/F, J/P | MBTI | 8 each (5 open + 3 follow-up) |
| Honesty-Humility, Emotionality, Extraversion, Agreeableness, Conscientiousness, Openness | HEXACO | 8 each |

`QuestionSelector` reads `profile.uncertain_dims_ranked()` and always targets the most uncertain dimension first, preferring open questions before follow-ups.

## Session Flow

```
Start
  └── QuestionSelector picks from bank  (Phase 4)
        └── User answers
              └── RoBERTa scores answer  (Phase 2)
                    └── ProfileManager.update()  (Phase 3)
                          └── Every 3rd turn: Ollama generates adaptive question  (Phase 6)
                                └── is_converged()?
                                      ├── No  → next question
                                      └── Yes → LLM writes final report  (Phase 6)
```

## Known Limitations

- MBTI confidence plateaus at ~47% after 8–12 turns — a larger or more domain-specific dataset would improve this
- HEXACO scores cluster near 0.5 — the Essays dataset uses binary labels; continuous labels would improve resolution
- ESTJ and ESFP have very few test samples (6–7 each) — F1 scores for these types are unreliable
- The J/P axis is the hardest to resolve — contradictory signals (hates change but works under pressure) are common and genuine
- Honesty-Humility is a derived label (average of Agreeableness + Conscientiousness) — treat its score with lower confidence
